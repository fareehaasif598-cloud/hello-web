## Reflection
For this Week 1 assignment, I created a personal profile page using HTML. My page includes an About Me section, a Skills and Interests section, an image, and links to my LinkedIn, GitHub, and email.

This assignment helped me practice using basic HTML structure and semantic tags such as header, main, section, and footer. I also learned how to add lists, links, images, and alt text. Since this was my first time using Git and GitHub, I learned how commits work and how they can be used to save progress in a project.
